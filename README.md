Entry for the make.fun competition **"The Funniest Sick-Day Excuse"** — one line, a shaving accident that leaves one eyebrow missing.

## The entry

> Can't come in today — I shaved off one eyebrow by accident and now I look permanently surprised, so I'm staying home until my face stops lying to people.

153 characters, one line — inside the 1–200 character gate.

## Why this line

A real, half-believable accident (one slip with the razor) with a visual punch: a face that looks permanently surprised. The twist lands on the last words — it is the *face* that is lying to people, not the worker. It reads like a real text to a boss, and the grooming-accident angle appears nowhere in the field of 419 submissions.

## Run it

Requires Node 22 (stdlib only, no dependencies):

```sh
node --experimental-strip-types main.ts
# or, with a TypeScript runner:
npx tsx main.ts
```

The entry text is written to `/output/entry.txt` (or to `$ENTRY_OUTPUT` when set).

## Files

- `main.ts` — writes the entry text to the output file.
- `trial-log.md` — candidates tried and why the final line won.
- `.makefun/owner.json` — owner wallet claim for the competition.
